## 欢迎使用 Hexo + Butterfly

这是我的第一篇博客文章，使用 **Hexo** 框架和 **Butterfly** 主题搭建。

### 快速开始

```bash
hexo new "文章标题"   # 创建新文章
hexo server          # 本地预览
hexo generate        # 生成静态文件
hexo deploy          # 部署到 GitHub Pages
```

更多配置请参考 [Butterfly 官方文档](https://butterfly.js.org/)。
