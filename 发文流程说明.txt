============================================================
  Hexo + Butterfly 博客发文完整工作流说明
  博客地址: https://jianglipear.github.io/my-blog/
  项目目录: C:\blog
============================================================


第一步：进入博客目录
------------------------------------------------------
  cd C:\blog

cd = Change Directory，切换到博客根目录，所有命令必须在此执行。


第二步：创建文章
------------------------------------------------------
  hexo new "文章标题"

Hexo 读取 scaffolds/post.md 模板，生成文件：
  source\_posts\文章标题.md

内容示例：
  ---
  title: 文章标题
  date: 2026-06-16 20:30:00
  tags:
  ---

--- 包裹的区域叫 Front Matter（YAML 格式），存储元数据。


第三步：编辑文章内容
------------------------------------------------------
用编辑器打开 source\_posts\文章标题.md，补充 tags、categories 和正文：

  ---
  title: 我的第一篇博客
  date: 2026-06-16 20:30:00
  tags:
    - Hexo
    - 教程
  categories: 技术
  ---

  ## 欢迎

  这是我的第一篇文章。

  ```javascript
  console.log("Hello Hexo");
  ```

  [Butterfly 主题文档](https://butterfly.js.org/)

- tags：标签，用于分类检索
- categories：分类（支持多级，如 [技术, 前端]）
- 正文：标准 Markdown 语法


第四步：本地预览（可选）
------------------------------------------------------
  hexo server

启动本地服务器，浏览器打开 http://localhost:4000 预览。
按 Ctrl+C 停止。


第五步：提交到 Git
------------------------------------------------------
  git add -A
  git commit -m "发布新文章：我的第一篇博客"
  git push

逐个说明：
  git add -A      将所有变更加入暂存区
  git commit -m    保存为版本快照，-m 后是说明
  git push         推送到 GitHub main 分支（SSH 免密）


第六步：部署上线
------------------------------------------------------

方式 A：GitHub Actions 自动部署（推荐）
  推送 main 后，Actions 自动执行：
    1. npm ci              安装依赖
    2. npx hexo generate   生成静态文件到 public/
    3. 推送 public/ 到 gh-pages 分支
  1-2 分钟后网站自动更新。

方式 B：本地手动部署
  hexo clean      清除缓存和旧文件
  hexo generate   重新生成静态文件到 public/
  hexo deploy     推送 public/ 到 gh-pages 分支

  一行等效：
  hexo clean && hexo generate && hexo deploy
